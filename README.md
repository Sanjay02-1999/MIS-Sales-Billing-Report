# MIS Sales & Billing Report - 10.26 Cr Project

## 📊 Project Overview
Analyzed sales billing data for 15 clients with total billing of **₹10.26 Crores**.
Created comprehensive MIS report with Pivot Table and Dashboard.

## 🔧 Tools Used
- Microsoft Excel
- Pivot Table & Pivot Chart
- Data Validation

## 📈 Key Insights
- **Total Sales:** ₹10.26 Cr
- **Paid Amount:** ₹6.10 Cr (59%)
- **Pending:** ₹2.85 Cr (28%)
- **Partial Paid:** ₹1.31 Cr (13%)
